# ⚔️ 勇者斗Boss（brave-game）

一款使用 **Vue 3 + TypeScript + Canvas 2D** 自研引擎开发的**像素风横版动作闯关游戏**，无需任何外部游戏引擎、美术素材与音频文件——精灵图、背景、特效与音效全部由代码程序化生成。

> 千年前，封印魔王的水晶破碎成五枚碎片散落大地，黑暗随之蔓延。少年「黎恩」从废墟中崛起，手持祖传长剑，踏上寻找水晶碎片、讨伐被黑暗侵蚀的守护者的征途。

---

## 🎮 玩法特色

- **8 大关卡**：翠绿草原 → 暗夜森林 → 炎之火山 → 永冻雪山 → 深渊洞窟 → 金色沙漠 → 浮空云巅 → 王者城堡
- **多阶段 Boss 战**：每关关底都有一位多形态 Boss（近战突袭 / 冲锋 / 范围轰炸 / 弹幕 / 召唤小怪 / 旋转攻击），血量低于阈值会进入狂暴阶段
- **武器与装备系统**：4 类武器（斩龙剑·近战、龙牙枪·穿透、精灵弓·远程、爆炎铳·散射）× 5 阶品级，另有 5 阶护甲，由怪物掉落与宝箱开出
- **宠物养成系统**：每打败一位 Boss 即可将其净化收服为伙伴，8 只宠物提供属性加成与专属攻击技能
- **隐藏区域与探索**：关卡中藏有隐藏石阶与特殊宝箱，等待发掘
- **可破坏环境**：木箱、炸药桶、尖刺陷阱、流沙等交互障碍物
- **精英怪与多波次战斗**：每个场景按波次刷怪，清理完毕开启传送门
- **剧情过场**：关卡前后有故事对话演出
- **存档系统**：进度自动保存于浏览器 `localStorage`

## 🛠️ 技术栈

- **框架**：Vue 3（Composition API + `<script setup>`）、Vue Router、Pinia
- **构建**：Vite 8、TypeScript
- **游戏引擎**：自研 Canvas 2D 引擎（`src/game/`），含物理系统、粒子系统、输入管理、背景动画器、精灵图程序化生成
- **音效**：Web Audio API 程序化合成（无需外部音频文件）
- **质量工具**：Vitest（单元测试）、Playwright（E2E 测试）、ESLint / oxlint / oxfmt

## 📦 环境要求

- **Node.js**：`^22.18.0 || >=24.12.0`
- 包管理器：推荐 **pnpm**（npm 亦可）

## 🚀 快速开始

```sh
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器（默认 http://localhost:5173）
pnpm dev
```

浏览器打开终端中提示的地址（通常为 `http://localhost:5173`）即可开始游戏。

### 生产构建与预览

```sh
# 构建生产版本（含类型检查，输出到 dist/）
pnpm build

# 本地预览生产构建
pnpm preview
```

### 测试与代码检查

```sh
pnpm test:unit          # 单元测试（Vitest）
pnpm test:e2e           # 端到端测试（Playwright，首次需 npx playwright install）
pnpm lint               # 代码检查
pnpm format             # 代码格式化
```

## 📂 项目结构

```
src/
├── components/          # Vue 组件（游戏画布、世界地图、宠物面板、剧情对话等）
├── views/               # 页面视图（GameView 主视图）
├── game/
│   ├── engine/          # 自研引擎（物理、粒子、输入、音效、精灵图生成…）
│   ├── entities/        # 游戏实体（玩家、Boss、敌人、武器、装备、宠物、道具）
│   ├── scenes/          # 游戏场景与关卡配置
│   └── types/           # 类型定义
├── router/              # 路由
└── stores/              # Pinia 状态（存档、装备、宠物、进度）
```
